# Pong Arena Multiplayer (2–4 players)

Браузерная Pong-игра для 2–4 игроков. Клиент — HTML/CSS/Canvas, сервер — Node.js + Express + Socket.IO. Сервер рассчитывает движение мяча и счёт, клиенты передают только положение своей ракетки.

## Структура

│   ├── style.css

## Перед публикацией: укажи адрес Render

После деплоя сервера Render выдаст адрес примерно `https://pong-multiplayer-server.onrender.com`.

Открой `client/app.js` и замени строку:

```js
const SERVER_URL = 'https://YOUR-RENDER-SERVICE.onrender.com';
```

на свой настоящий адрес Render, без `/` в конце. Например:

```js
const SERVER_URL = 'https://pong-multiplayer-server.onrender.com';
```

Не оставляй `YOUR-RENDER-SERVICE` в опубликованном клиенте.

## 1. Загрузить проект в GitHub

1. Создай новый репозиторий, например `pong-multiplayer`.
2. Распакуй архив и загрузи **все файлы и папки** в корень репозитория.
3. Убедись, что `package.json`, `server.js` и `render.yaml` лежат в корне, а клиентские файлы — в папке `client`.

## 2. Деплой сервера на Render

1. Открой [Render](https://render.com/) и войди в аккаунт.
2. Нажми **New → Web Service** и подключи GitHub-репозиторий.
3. Если Render предлагает использовать `render.yaml`, подтверди. Либо задай вручную:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/health`
4. Создай сервис и дождись успешного деплоя.
5. Скопируй публичный URL сервиса, например `https://имя-сервиса.onrender.com`.
6. В `client/app.js` вставь этот URL в `SERVER_URL` и сохрани изменения в GitHub.

Необязательно, но рекомендуется: в Render → Environment добавь переменную `CLIENT_ORIGIN` со значением URL сайта Netlify, например `https://имя-сайта.netlify.app`. Если переменная не задана, сервер разрешает CORS с любого origin. Если задаёшь её, укажи точный адрес сайта без завершающего `/`. Для нескольких разрешённых origin перечисли их через запятую.

**Важно про бесплатный тариф:** сервис может засыпать после периода бездействия. Первое подключение после сна может занять некоторое время.

## 3. Деплой клиента на Netlify

1. Открой [Netlify](https://www.netlify.com/) и выбери **Add new site → Import an existing project**.
2. Подключи тот же GitHub-репозиторий.
3. В настройках сборки укажи:
   - **Base directory:** оставить пустым
   - **Build command:** оставить пустым
   - **Publish directory:** `client`
4. Нажми **Deploy site**. `netlify.toml` уже задаёт папку публикации `client` и Node.js 20 для окружения сборки; сборка клиенту не нужна.
5. Открой сайт Netlify и проверь, что `SERVER_URL` в `client/app.js` указывает на Render.
6. Если ты добавляешь `CLIENT_ORIGIN` в Render, укажи домен опубликованного сайта Netlify и после этого перезапусти/задеплой Render.

## 4. Как играть

1. Открой сайт Netlify.
2. Введи ник и нажми **Создать комнату**.
3. Отправь друзьям пятизначный код комнаты.
4. Друзья вводят код и нажимают **Войти**.
5. Когда вошли минимум два игрока, нажмите **Начать игру**.
6. Ракетка двигается мышью или касанием; на клавиатуре используй стрелки или WASD. Для ракеток слева/справа используются ↑/↓, для верхней/нижней — ←/→.

### Правила

- Комната рассчитана максимум на 4 игроков.
- При 2 игроках ракетки находятся слева и справа; при 3 добавляется верхняя; при 4 — нижняя.
- Если мяч пролетает мимо ракетки игрока, остальные игроки получают по одному очку.
- Побеждает первый игрок, достигший 10 очков.
- После победы можно вернуться в лобби и начать реванш.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Сервер запустится на `http://localhost:3000`. Для локального тестирования замени `SERVER_URL` в `client/app.js` на `http://localhost:3000`, затем открой `client/index.html` через локальный статический сервер (например, расширение Live Server в VS Code). Для тестирования на одном компьютере можно открыть клиент в нескольких вкладках.

## Устранение неполадок

- **«Нет соединения»** — проверь, что Render-сервис завершил деплой и URL в `SERVER_URL` указан правильно.
- **Комната не найдена** — проверь код, регистр не важен, но лишних символов быть не должно.
- **CORS-ошибка** — проверь `CLIENT_ORIGIN` в Render. Если переменная задана, там должен быть точный URL сайта Netlify.
- **Не подключается после изменения URL** — сохрани `client/app.js` в GitHub и дождись повторного деплоя Netlify.

## Примечания

Это стартовый игровой проект, а не система аккаунтов: ник не защищён паролем, а игроки идентифицируются Socket.IO-соединением. Комнаты существуют в памяти процесса и исчезнут при перезапуске сервера. Для публичного крупного проекта стоит добавить лимиты запросов, проверку входных данных, устойчивое хранилище и дополнительные средства защиты.
